# 电影短评情感标注任务（200 条）

## 任务

你将看到 200 条豆瓣电影短评（每条一个 JSON 行，格式 `{"n": 编号, "text": "评论内容"}`）。
请为每条评论判断作者对**这部电影本身**的情感倾向，标为以下三类之一：

- **正面**：表扬、推荐、肯定（包括隐晦的夸奖）
- **中性**：客观描述剧情/演职人员、纯感慨无立场、褒贬各半难分、或与电影本身无关的内容
- **负面**：批评、吐槽、失望、劝退（包括反讽/阴阳怪气的贬义）

## 判定要点

1. 只看 `text` 字段，**不要**参考其他任何信息
2. 关注作者对**电影**的态度，不是对剧情、演员个人或社会现象的态度
3. 反讽/玩梗要看上下文推断真实态度（如打 1 星却说"神片"= 负面）
4. 没有明确褒贬、纯客观描述或纯情绪感慨 → **中性**
5. 拿不准时选**中性**，不要硬猜

## 参考示例（来自另一个已标注数据集）

| 评论 | 标签 | 理由 |
|---|---|---|
| 画面太美了，配乐也绝，一晚上看了两遍还意犹未尽 | 正面 | 明确赞赏 |
| 女主演技好，男主像个木头，剧情也老套 | 中性 | 褒贬各半 |
| 两个小时的垃圾时间，编剧是来搞笑的吧 | 负面 | 强烈批评 |
| 有些人只能留在记忆里 | 中性 | 诗意感慨，无明确立场 |
| 神片子！传统手艺用特效拍，侮辱观众智商 | 负面 | 反讽=贬义 |

## 输出格式

在 `friend_IAA_200.jsonl` 同目录下新建 `friend_labels.txt`，每行一条：

```
0 正面
1 中性
2 负面
...
```

共 200 行，`n` 对应原文件编号，标签只能是 `正面`/`中性`/`负面` 三选一。
预计用时 40~60 分钟（每条 10~20 秒）。标完发我即可。
